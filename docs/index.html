Titanium v2.0 Architectural Innovations

Engineering breakthroughs that outperform standard micro-routers.

🔀
lwIP DNAPT Port Forwarding
Expose web dashboards, IP security cameras, or gaming servers on your local repeater network to the upstream network with zero CPU overhead using native Layer 3/4 translation.
🛡️
Station MAC Address Cloning
Authenticate your smartphone or laptop on hotel, university, or airport captive portals, then clone its MAC to the ESP32 to immediately share the authenticated internet connection with all your devices.
🚫
Hardware DNS AdBlocker Sinkhole
Hardware UDP port 53 DNS sinkhole immediately returns 0.0.0.0 for known tracking and ad networks (DoubleClick, Google Analytics, Telemetry) with real-time blocked counter telemetry.
🎯
1D Kalman Filter RSSI Smoothing
Eliminates ping oscillation caused by 2.4 GHz multipath signal reflection using discrete state estimation (Q=0.008, R=4.50), preventing false roams and packet jitter.
⚡
Zero-Jitter WIFI_PS_NONE Lock
Completely disables 802.11 modem sleep. The ESP32 radio never enters sleep states, eliminating the 20–100ms latency spikes typical of stock repeaters.
⏱️
15s Hardware Task Watchdog (TWDT)
Integrated ESP-IDF hardware watchdog timer. If an unrecoverable network stall or thread lock occurs, the silicon initiates an automatic clean recovery reboot within 15 seconds.
🌐
Zero-DNS mDNS Resolution
Access your repeater management dashboard at http://aetherpulse.local on iOS, macOS, Windows, Android, and Linux without ever having to remember or lookup IP addresses.
📱
Mobile Glassmorphism Web App
Ultra-responsive multi-tab dashboard embedded directly on chip. Features real-time SVG throughput graphs, priority network failover pools, and drag-and-drop OTA updates.
