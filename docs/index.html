ESP32 Web Installer

Flash AetherPulse Wi-Fi Repeater & lwIP NAPT firmware directly over USB via Web Serial. Zero IDE or Python setup required.

1. Select Firmware Release
Target: ESP32-D0WD-V3 / WROOM-32 (4 MB Flash)
Web Serial requires a desktop Chromium browser (Chrome, Edge, Brave, or Opera) over HTTPS. Use the manual esptool.py command below on other platforms.
Web Serial is blocked in non-secure contexts. Open this installer via https:// or localhost.
Connect your ESP32 via a data-capable USB cable, click Install, and select your CP2102 / CH340 serial port.

Serial Port & Driver Troubleshooting
A
No serial port appears in browser picker
Install Silicon Labs CP210x VCP or WCH CH340 drivers, and verify your USB cable carries data lines.
B
Failed to connect / Timed out waiting for packet header
Hold the BOOT (IO0) button, tap EN/RST once, then release BOOT after flashing starts.
C
Linux permission denied on /dev/ttyUSB0
Add your user to dialout (sudo usermod -aG dialout $USER) and close any active serial monitor or ModemManager lock.
